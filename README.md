이런 형태로 images와 labels에는 원래 train의 이미지와 라벨이 포함되어 있다. 

output으로 시작하는 것들은 증강을 시도한 것들에 대한 결과가 들어가있는 파일이다. 

이 파일 각각 내부에 images와 labels 파일이 있다. 

val에는 나중에 모델을 활용하여 돌릴 때 검증용으로 사용할 이미지와 라벨들이 포함된 파일이다. 

'yolov8_training_results'에는 모델을 활용하여 학습을 시킨 후 결과에 대한 시각화와 지표들이 포함된 파일이다.
